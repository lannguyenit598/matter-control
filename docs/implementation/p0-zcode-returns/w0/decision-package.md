## 2. INTA-PROOF-DEC — W0 proposal (preparation only; no adoption, no execution)

**Observed facts (from received R5 sources, exact lines in the frozen review):** during-samples are taken only after `poll() is None` (coordinator.py:505-514) but are counted unconditionally after the probe; no per-sample timestamp, alive predicate or child `[startUTC, exitUTC]` interval is retained anywhere; test 35 (`poll_sequence=[None,1]`) passes `VALID_COMPLETE_INPUT`, demonstrating accepted point-in-time semantics. The launcher record (harness-dev.mjs:93-111) has one timestamp and no Next/Node binary hash. Conclusion: sampled absence at N instants + one post-probe cannot prove **continuous** never-listen, regardless of ordering, delays or retries.

**Proposal options (evidence basis only; the approved criterion itself is NOT relaxed here):**

- **P-A — Interval-bound evidence upgrade (minimum, regardless):** retain per-sample `(sampleUTC, pollBefore, childIdentity)` and capture the child's true `[startUTC, exitUTC]` interval (start from the existing `lstart`/`child_start_utc` capture; exit via handle reap classification). Evaluator rejects any sample outside the interval and requires a closed interval + `spawnCalled:false` + guard hash + zero observer requests + exact refusal phrase. Yields: interval-bound sampled absence with complete retained evidence. **Does NOT prove continuity** — a listener could exist between samples.
- **P-B — Deny-by-construction (recommended as the only truthful continuity basis):** execute the launcher child under an OS-enforced no-socket-listen constraint for the refusal path (macOS `sandbox-exec` profile denying listen, or equivalent documented mechanism), so never-listen is enforced rather than sampled; evidence = profile text + exec receipt + exit status + refusal phrase + zero-upstream observer. This satisfies the approved criterion without delay/retry/waiver. Scope: harness-transport change only, source-visible, independently reviewable, testable with a deliberate listen-attempt fixture proving the deny fires.
- **P-C — Explicit criterion re-adjudication (honest fallback):** if neither P-A nor P-B is adopted, return to the Human PO: either accept "interval-bound sampled absence + full record + zero upstream" as the defined evidence basis for the fast-refusal check (a material acceptance decision), or descope the continuity claim explicitly. No silent relaxation.

**Recommendation:** adopt P-B for the refusal path (it is the only option that meets the criterion as written), with P-A implemented anyway as the evidence floor. Decision needed **before** INTA-CORR-NEXT activation; the one bounded repair contract then implements the adopted basis plus the combined source/binding/identity/test fixes listed in the R5 addendum §4 (mandatory CLI stage binding, one receipt schema/hash/realpath/expected-binary map, durable identity record, strict non-null identity/once-only cleanup, additive Z01 errata, explicit attempt dir). If ZCode implements it, review routes to a qualified nonauthor (INTA-REVIEW-NEXT).
