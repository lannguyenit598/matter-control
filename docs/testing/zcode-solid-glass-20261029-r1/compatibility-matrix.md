## Approach selection

- **CHOSEN: limited source-derived CSS/token adaptation** — glass material expressed as MatterControl-owned tokens + a small, explicitly mapped rules block in `globals.css` (+ `data-slot` hooks only where needed), preserving house components, typography (Be Vietnam Pro), density, IA and all legal-state colors.
- Rejected: wholesale stylesheet import (upstream's delete-variables instruction + `.dark` activation + 133 unmatched `data-slot` selectors would break the current system and the other writer's work).
- Rejected: verified-stylesheet-integration via a compatibility shim (would still fight Codex's active shell/Button edits and pin us to upstream selector shapes we do not emit).
- Rejected: component migration (forbidden by scope; no new dependency or parallel system).
