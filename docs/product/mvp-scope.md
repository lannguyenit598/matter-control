# MVP Scope and Release Boundaries

Source: approved [capability register](../requirements/p0-p1-p2-priorities.md), Step 01. Owner: Codex. Status: scope APPROVED_INPUT; detailed acceptance APPROVED_BY_PO, 2026-10-24, subject `572835a`; [approval record](../ai-sdlc/step-01-approval.md).

All 20 REQ-MC-P0 entries remain in full MVP. [SRS](../requirements/srs.md) maps each stable capability to FR-001..020; no capability is dropped because of implementation or hosting difficulty. The 14 P1 and 7 P2 entries retain their existing IDs and priorities.

| Boundary | P0 minimum / approved OBD-03 boundary | Deferred depth |
|---|---|---|
| Legal records | Typed Requirement/Action, basic Decision/Finding/Risk linked to matter and follow-up | P1 structured decisions, advanced findings/risks; P2 intelligence |
| Entity | Referenced participant/entity label and context | P1 master/temporal relations/ownership provenance; P2 beneficial ownership graph |
| Signature | Record required signature evidence and partial/full observations on a specific version | P1 signature tracking automation; no e-sign execution implied |
| Filing | Track package requirements, version, submission, receipt, authority waiting, supplements and outcome | P1 advanced packages; no regulator integration implied |
| Reporting | Authorized deterministic delta draft/export with explicit baseline/as-of and provenance | P1 managed issued-report lifecycle and retained historical snapshots |
| Views | Current scope/filter and grid/Control Room navigation | P1 saved views and management-ready export |

Early slice proposal: one requirement → action → independent proof → dependency change → history → delta, with permission/concurrency negatives. Internal alpha proposal: all three workflows on Atlas-derived progression fixtures, explicit gaps permitted and recorded. Full MVP: all P0/GW criteria plus approved security/NFR checks and no unresolved critical/high correctness defects. Slice/alpha are not full MVP.

Non-goals: generic task manager, legal-themed Jira, simple spreadsheet replacement, virtual data room, legal AI chatbot, generic workflow builder; automated legal advice, payment/transfer execution or statutory filing guarantees. No solution architecture, schema, high-fidelity UI or deployment is part of Step 01.

Cloudflare Free Tier/$0 per defined workload and supplied Go/Next.js templates remain constraints, not feasibility evidence. OBD-09 must expose real conflicts; no silent technology substitution or scope cut.
