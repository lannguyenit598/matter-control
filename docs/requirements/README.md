# Requirement Register

Product baseline: [approved product](../product/README.md). Source for all REQ-S00 rows: [original Step 00 request](../ai-sdlc/step-00-request.md). These are bootstrap requirements, not invented MVP feature requirements.

| ID | Requirement | Acceptance |
|---|---|---|
| REQ-S00-001 | Preserve product/roles and stop boundaries | Approved positioning retained; no features, production or unapproved integration |
| REQ-S00-002 | Verify five named external agents | CLI/API/MCP, invocation, workspace, Git, handoff, result and permission evidence or explicit unknown/failure for each |
| REQ-S00-003 | Define the full AI SDLC | All 12 stages, owner, artifact and exit gate; six required methods operationalized |
| REQ-S00-004 | Establish project governance | Charter, RACI, responsibilities, DoR/DoD, gates, handoff, changes, decisions, risks, trace and status exist |
| REQ-S00-005 | Establish task contract/lifecycle | All required fields/statuses, evidence-based DONE and independent review |
| REQ-S00-006 | Git and versioned source of truth | Required 12 docs directories and nine named files; existing content inspected before changes |
| REQ-S00-007 | Supported agent instructions | AGENTS.md and supported formats with sources; unverified loaders clearly identified |
| REQ-S00-008 | Trace each requirement through delivery | Task/test/review/release references present, including explicit pending/N/A reasons |
| REQ-S00-009 | Report readiness and stop at Step 00 | Status/readiness packet; next-step scope marked proposed; no automatic Step 00A execution |

Future product requirements use REQ-MC-XXX with source, actor/user goal, business rules, observable acceptance scenarios, priority, NFRs, approval and version. They will be defined after this bootstrap, not inferred from repository templates.
